# 关于这个博客

你好，我是一名有 **10 年经验**的 Java 后端工程师，专注于**高并发、分布式与支付 / 金融系统**。

我的经历（技术视角，隐去具体雇主）：

- **某头部旅游平台**：数据化运营平台，Dashboard 可视化与 OLAP 查询加速（OpenTSDB / Kylin / Presto / ES）；
- **某出行平台**：运维管理平台，千万级 IOT 设备下的**工单系统**与**薪资清结算系统**；
- **某直播电商平台**：商品搜索（ES）、多级缓存、库存扣减、商户权限、活动优惠券；
- **某跨境支付公司**：**跨境支付收款平台**，作为核心领域 Owner，主导系统重构（人效显著提升、生产问题大幅下降、0 资损），从 0 到 1 建预入账子领域。

这个博客是我在 **面试前** 准备的资料库：把复习内容按模块沉淀，结合我**真实做过的项目**深入讲解，并覆盖 AI / LLM 等最新技术探索。目标是「讲得清原理，也讲得清落地」。

## 十大模块

- **① 复习规划**：总览、节奏与可追踪的进度看板；
- **② 计算机基础**：并发 / JMM / 网络 / JVM；
- **③ 算法与数据结构**：按题型建错题本，映射到项目场景；
- **④ 系统设计**：高可用跨境支付、支付全链路架构、账务与清结算、分布式事务；
- **⑤ 项目深挖**：多家一线公司真实经历复盘 + 支付亮点与高可用；
- **⑥ AI / 新技术探索**：LLM 落地、向量检索与 RAG 实践；
- **⑦ Java 与 Spring**：JVM、Java 并发、Spring 全家桶与 MyBatis；
- **⑧ 术语与考点**：核心术语详解、基础知识点与面试深度追问；
- **⑨ 项目管理**：研发流程、风险、进度、真实问题复盘；
- **⑩ 团队管理**：技术领导力、带团队、冲突与绩效。

## 写作原则

1. **详细深入**：不只列结论，讲清原理 → 工程取舍 → 项目结合；
2. **结合真实项目**：以我做过的跨境支付、工单薪资、电商搜索、数据平台为锚（幂等、渠道路由、对账、风控、状态机、SPI、任务补偿）；
3. **最新技术**：把 AI / LLM 的落地边界与 ROI 讲透，而不是堆名词。
